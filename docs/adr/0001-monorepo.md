# ADR 0001：单仓、契约先行

状态：已采纳（2026-11-02）

## 背景

手机、手表、电脑三端与云端都会解析同一份协议。分仓会导致版本错位，而在这里版本错位就是安全洞：设备可能接受云端以为会被拒绝的字段。

## 决定

- 协议、设备核心、各端 App、工具放在同一个仓库，目录即分层：`apps/* → core/* → protocol/`（只读）。
- `protocol/` 只放数据（schema、策略、向量、规范），不放代码。
- 云端编排代码**不放进本仓库**（DEVELOPMENT.md 第 3 节的 constraints）；`tools/vector-runner/py` 是协议的 Python 参考实现，未来 hub 必须与它跑同一份向量。
- 金标准向量只有一份：`protocol/vectors/`，Kotlin 与 Python 都读它。

## 后果

改一个字段要同时改 schema、策略、向量、两份实现；CI 强制两侧跑向量。代价是仓库变大，收益是版本永远一致。
