# ADR 0004：每类数据只有一个写者

状态：已采纳（2026-11-02，实现属 Phase 1/3）

## 背景

多端离线编辑会产生冲突。自动合并文本、自动择一时钟，都会让人无法解释"为什么我的提醒变了"。

## 决定

| 数据 | 权威方 | 策略 |
| --- | --- | --- |
| 聊天记录 | 云 | 只追加，按 server seq 排序 |
| 备忘 | 云 | 条目不可变 + 修订链；两端各改一次保留两个版本标"冲突副本"，由用户合并 |
| 设置/偏好 | 云 | 字段级 LWW（混合逻辑时钟）；确认级相关设置只在手机本机生效，不经云下行 |
| 日历事件 | 手机系统日历 | 云只存镜像与 event_uid 映射；创建带幂等键 |
| 闹钟/计时器 | 执行设备 | 云只记"已下发"，真实状态以设备回执为准 |
| 定时任务 | 云 | 单写者；端上修改等于发意图给云 |
| 长期记忆 | 云 | 端上只能提交"记忆建议" |
| presence/电量 | 各设备自报 | 软状态 + TTL，不做冲突解决 |

## 后果

不做自动文本合并；同步 API 必须带 `base_rev` 并在冲突时显式返回冲突副本，而不是静默覆盖。
