# ADR 0006：电脑端只读文件搜索暂不接入协议

状态：**待用户拍板**；默认按选项 A 执行（不接入 v1）

## 背景

`apps/desktop/capabilities/file_search.py` 是现有的只读搜索存根。它不在 9 种白名单意图内。文件内容/文件名是提示注入与外带的经典入口。

## 选项

- **A（默认，v1 不接入）**：只保留为本地诊断工具，不进入信封、不被云端调用。最稳，Phase 0/1/2 都不需要它。
- **B（需用户明确同意）**：协议 v1.1 新增第 10 种 `local_search`：只读、仅限用户配置的根目录、默认只回文件名/路径/短摘要、结果一律 `tainted=true`、不得流入 web_search/save_note/任何外发。

## 决定

尚未决定。本 ADR 记录默认值：**不接入**。未得到用户明确选择前，任何代码不得把 `file_search.py` 接到信封或网络路径上。

## 后果

电脑端 Phase 2 的文件能力先用白名单内的 open_app/web_search/set_timer/save_note 验证；文件搜索等 v1.1 的污点机制落地后再谈。
